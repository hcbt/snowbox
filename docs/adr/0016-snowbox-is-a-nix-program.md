# Snowbox is a Nix program the user runs

v1 is a local tool for the person who already lives in Nix. A macOS `.app` is packaging for other people; that is the deferred platform/distribution story.

Install and run via Nix (`nix run`, a flake, devenv). The user starts the Daemon. It is not launchd-by-default and not Docker Desktop. Linux v1 is the same command.
